📋 API Endpoints Summary - Complete CRUD Operations

All endpoints organized by resource and HTTP method. Perfect for screenshots demonstrating GET, POST, PUT/PATCH, DELETE operations.

🔵 Microservice 1: User & Profile Service

Resource: Users
Method Endpoint Description
GET /users List all users (with pagination & filters)
GET /users/{user_id} Get a specific user by ID
POST /users Create a new user (requires JWT)
PATCH /users/{user_id} Update user (partial update)
DELETE /users/{user_id} Delete a user (requires JWT)
Resource: Profiles
Method Endpoint Description
GET /profiles List all profiles (with pagination & filters)
GET /profiles/{profile_id} Get a specific profile by ID
POST /profiles Create a new profile
PATCH /profiles/{profile_id} Update profile (partial update)
DELETE /profiles/{profile_id} Delete a profile
OAuth2/Authentication
Method Endpoint Description
GET /auth/login Initiate OAuth2 login with Google
GET /auth/callback OAuth2 callback - returns JWT token

🟢 Microservice 2: Catalog & Inventory Service

Resource: Catalog Items
Method Endpoint Description
GET /catalog/items List all catalog items (with pagination & filters)
GET /catalog/items/{id} Get a specific catalog item by ID
POST /catalog/items Create a new catalog item (triggers Pub/Sub event)
PUT /catalog/items/{id} Update catalog item (full update)
DELETE /catalog/items/{id} Delete a catalog item

🟡 Microservice 3: Order & Rental Service

Resource: Orders
Method Endpoint Description
GET /orders List all orders (with filters: status, userId, itemId, dates)
GET /orders/{orderId} Get a specific order by ID
POST /orders Create a new order
DELETE /orders/{orderId} Cancel an order
PATCH /orders/{orderId}/status Update order status (pending, active, cancelled, returned)
GET /orders/{orderId}/logs Get order activity logs
POST /orders/{orderId}/confirm Confirm order (returns 202 Accepted with job ID)
Resource: Jobs (Async Operations)
Method Endpoint Description
GET /jobs/{jobId} Get job status (for async order confirmation)

🟣 Composite Microservice

The composite service encapsulates atomic services and adds composite-specific behavior (FK validation, parallel execution, merged search).

Proxied Endpoints (Delegation)
Method Endpoint Description
GET /users/{user_id} Get user (delegates to User Service)
GET /items List items (delegates to Catalog Service)
GET /items/{item_id} Get item (delegates to Catalog Service)
GET /orders/{order_id} Get order (delegates to Order Service)
Composite-Specific Endpoints
Method Endpoint Description
GET /readyz Health check
POST /orders Create order with FK validation and parallel execution (threads)
POST /orders/{order_id}/confirm Confirm order (returns 202 Accepted with job ID)
GET /jobs/{job_id} Get job status
GET /search Multi-source search (aggregates catalog + orders)
